无线与路由技术动态 2026-04-04

发表于2026-04-04|更新于2026-10-21|技术动态
|阅读量:

本期摘要

本期最值得关注的是 FCC 禁售非美国产路由器对开源固件生态的深远冲击，以及 ath11k/ath12k 驱动修复上游合并带来的 WiFi 性能提升；与此同时，全球电信资本开支下行与 AI 基础设施竞赛的矛盾正成为运营商的新命题。

Linux 动态

FCC 路由器禁售令对自由软件意味着什么

Software Freedom Conservancy（SFC）发文深度剖析 FCC 近期颁布的禁止销售所有非美国制造家用路由器政策对开源社区的影响。SFC 本身是 OpenWrt One 路由器背后的组织，该禁令直接威胁到社区驱动的开放硬件路线。文章指出，若硬件来源受限，用户在设备上运行自由软件（如 OpenWrt）的权利将大幅缩水。

🔗 原文

Ubuntu 的 GRUB 替换计划

LWN 深度报道 Ubuntu 正在推进逐步迁离 GNU GRUB 2 的路线图。GRUB 是 x86_64 Linux 系统最主流的引导程序，支持 UEFI/BIOS 双模式与多文件系统，但其维护复杂性和安全历史问题促使 Ubuntu 寻求替代方案。此举可能影响大量依赖 GRUB 自定义的服务器和嵌入式 Linux 部署场景。

🔗 原文

周五安全更新汇总

本周五多个主流发行版发布安全更新：AlmaLinux 修复 kernel、grafana、rsync 等组件漏洞；Debian 更新 chromium 与 libpng1.6；Fedora 修补 bind9-next 与 nginx-mod-modsecurity；Red Hat 针对 container-tools:rhel8 发布补丁。涉及路由器和网络基础设施场景的运维人员应优先关注 kernel 与 DNS 相关修复。

无线通信动态

Dell’Oro：2026 年全球电信资本开支预计下降 2%

市场研究机构 Dell’Oro 最新预测显示，2026 年全球电信 capex 将同比下滑约 2%，此后至 2030 年仅以约 1% CAGR 温和复苏。这一趋势反映出 5G 大规模建设红利期已过，运营商整体进入收缩与整合周期，新一轮投资高潮需等待 6G 标准落地。

🔗 原文

ABI Research：AI 算力网格或成下一场电信军备竞赛

ABI Research 分析师指出，电信运营商正在评估 NVIDIA AI Grid 方案，但当前边缘 GPU 部署在时延收益与成本回报上尚无强劲商业案例，仅物理 AI（Physical AI）场景可初步证明其合理性。报告预计，AI 基础设施将随 6G 网络建设节奏逐步渗透，短期内不会大规模铺开。

🔗 原文

Amazon 洽购 Globalstar：卫星直连市场争夺加剧

据报道，Amazon 正与 Globalstar 就约 90 亿美元收购事宜展开谈判，而此前市场盛传 SpaceX 也有意竞购。Globalstar 是 Apple 紧急卫星直连服务（Emergency SOS via satellite）的后端运营商。分析师认为，此次竞购折射出低轨卫星直连（D2D）赛道的战略价值持续攀升，各大科技巨头卡位意图明显。

芯片 & 硬件

Samtec 亮相 embedded world 2026

连接器与信号完整性方案商 Samtec 在本届 embedded world 展会（德国纽伦堡）大规模亮相，展示了面向嵌入式系统的高速互连产品线。embedded world 自 2003 年起已成为全球嵌入式生态最具影响力的年度聚会，覆盖从 MCU 到工业级无线模组的完整产业链，是观察嵌入式无线硬件趋势的重要窗口。

🔗 原文

路由器 & OpenWrt

ath11k / ath12k 上游补丁修复 AMPDU 会话误终止问题

Phoronix 报道一个已合并进 Linux 7.0-rc7 的上游补丁，修复了 ath11k 和 ath12k 驱动在处理 AMPDU 会话终止请求时错误地停止了另一个会话的 Bug。根本原因是传入参数混淆，导致高负载下 WiFi 吞吐量随机下降。该修复覆盖所有基于 Qualcomm 的 WiFi 6/6E/7 设备，OpenWrt 用户可期待后续版本集成此修复。

🔗 原文

OpenWrt 25.12.2 升级后出现 DNS 泄漏问题

有用户在 Linksys WRT32X 上从 24.10.4 升级至 OpenWrt 25.12.2 后出现 DNS 泄漏。由于 attended sysupgrade 服务器返回错误，用户被迫手动刷入 .bin 固件并恢复出厂设置，重新配置后仍发现 DNS 查询绕过预设的加密 DNS 通道。该问题提示跨大版本升级后需重点验证 DNS 策略路由配置是否被重置。

🔗 原文

WWAN 接口上配置 WireGuard 的稳定性困境

社区用户反馈在路由器通过 Wi-Fi 上联（WWAN 模式）时配置 WireGuard VPN 隧道存在持续掉线问题。该场景在 4G/5G CPE 二级路由和无线中继部署中较为常见，链路切换与 WireGuard 的 keepalive 机制之间的交互是主要排查方向，目前社区正在整理可复现的配置方案。

🔗 原文

SQM CAKE 多核调度问题：MT7621 平台仅单核工作

使用 openwrt-imagebuilder-25.12.1 为 MT7621 平台构建镜像的用户发现，开启 SQM（Smart Queue Management）并使用 CAKE 队列规则后，负载仅集中在单个 CPU 核心，未能充分利用四核算力。这与 Multi-Queue 的预期行为不符，可能涉及 kmod-sched-cake 与平台驱动的多队列绑定配置，社区正在排查是构建配置问题还是驱动层缺陷。

🔗 原文

TP-Link MR6400 不同硬件版本 ttyUSBx 接口差异

用户对比同型号 TP-Link MR6400 的 v5.3 与 v7.0 发现，v7.0 正确暴露 ttyUSBx 串口节点，而 v5.3 则没有，严重影响批量依赖串口管理的部署场景。该现象提示即便型号相同，不同硬件版本的 Device Tree 或内核驱动配置可能存在显著差异，采购前需核实具体硬件 revision。

编辑小结

本周最值得持续追踪的有两条主线：其一是 FCC 路由器禁售令，这不仅是贸易政策问题，更直接关乎 OpenWrt 等开源固件未来可刷机的硬件供应链，SFC 的介入说明开源社区已将其视为生存议题。其二是 ath11k/ath12k AMPDU 补丁的上游合并，对大量使用 Qualcomm 方案的路由器用户而言是实质性的稳定性改善，建议关注 OpenWrt 何时将该补丁 backport 至稳定分支。此外，全球电信 capex 下行与 AI 算力入网的结构性矛盾预计将在 2026 年持续发酵，运营商的取舍将深刻影响未来 WiFi Offload 与私有网络的投资节奏，值得长期关注。
