无线与路由技术动态 2026-11-18

发表于2026-11-18|更新于2026-11-18|技术动态
|阅读量:

本期摘要

本期 Linux 内核迎来 7.3.5 等三个稳定版更新，Redis 分支 Redict 宣告弃用并建议迁移 Valkey；OpenWrt 社区围绕 25.12 稳定版降级、LTE 一体机选购与老设备刷机文档持续活跃。

Linux 动态

Redict 弃用，官方建议迁移至 Valkey

Drew DeVault 宣布，为应对 Redis 2024 年许可证变更而创建的 Redis 分支 Redict 已停止维护，推荐用户转向 Linux 基金会支持、采用宽松许可证的 Valkey。两者相互兼容，迁移成本较低。

🔗 原文

三个稳定内核同日发布

Greg Kroah-Hartman 宣布了 7.3.5、6.18.64 和 6.12.118 三个 stable 内核，每个版本均包含大量重要修复。使用对应系列内核的发行版与嵌入式设备建议跟进评估。

🔗 原文

周二安全更新汇总

AlmaLinux 等多个发行版发布安全更新，覆盖 .NET 系列、bind、dovecot、dpdk、emacs 等大量软件包。运行相关服务的主机应尽快核对受影响版本。

🔗 原文

Zellij：带 Web 服务的终端复用器

Zellij 是终端复用器领域的新成员，提供分屏、会话管理等能力，与 GNU Screen、tmux 类似，但额外内置 Web 服务器，可通过浏览器访问终端会话。对远程调试路由器串口与嵌入式设备有一定想象空间。

🔗 原文

无线通信动态

Amazon Leo 卫星发射再遇挫折

ULA 二十年来首次发射失败，摧毁了 40 颗 Amazon Leo 卫星，对亚马逊的卫星互联网计划构成又一次打击。星座部署节奏与后续发射排期或将受到影响。

🔗 原文

BASF：AI 加速而非佐证私有 5G 价值

BASF 表示，AI 正在加速私有 5G 的采用，而非为其提供合理性论证；同时其现有边缘基础设施使 AI-RAN 并不适配。这一经验对工业 AI 与专网部署的常见假设提出了挑战。

🔗 原文

iBwave：私有 5G 规划不能只看覆盖

iBwave 市场战略总监 Nazim Choudhury 讨论了私有 5G 与既有无线基础设施集成时的挑战，以及工业环境对网络的特殊要求。规划阶段需要把干扰、容量与既有系统共存纳入考量。

🔗 原文

光骨干网：AI 基础设施的隐形底座

AI 基础设施投资正沿两个方向扩张：为模型训练扩展大规模计算集群，同时提升分布式容量以支撑快速增长的推理需求。光传输网络在其中承担关键的连接角色。

🔗 原文

WiFi 标准 & 技术

Cambium 之后：MDU Wi-Fi 供应商格局重排

Cambium Networks 崩塌后，美国多住户单元（MDU）Wi-Fi 供应商面临重新洗牌：RUCKUS 份额下滑，TP-Link 面临监管审查，Cambium 易主。Maravedis 梳理了竞争者与风险点，值得关注企业级 Wi-Fi 供应链的读者跟踪。

🔗 原文

Wi-Fi Forum 2027 开放注册

会议页面指出，Wi-Fi 已远超传统无线接入技术的角色：随着企业现代化、AI 负载激增以及运营商推进融合连接战略，Wi-Fi 正演变为更广泛的连接基础设施组成部分。

🔗 原文

芯片 & 硬件

Silicon Creations CTO 谈先进节点时钟 IP

Paweł Banachowicz 自 2012 年加入 Silicon Creations，主导设计了数百个 PLL 与时钟 IP，聚焦 FinFET 与 GAA 工艺。访谈涉及公司在先进节点设计能力上的建设，对理解高速接口与射频时钟方案有参考价值。

🔗 原文

更快的 HBM 能否解开 AI 内存瓶颈

HBM4 提升了接口宽度与可用带宽，定制 HBM 架构则为优化内存连接方式提供了空间。文章指出，带宽本身并不能单独决定下一代 AI 加速器的性能，互联与封装同样关键。

🔗 原文

Everspin 借 LPDDR 标准推广 MRAM

JEDEC 一个探索性任务组正在评估控制器厂商如何以硬 IP 方式支持 MRAM，使其兼容较新的 LPDDR 实现。若路线走通，MRAM 有望在嵌入式与边缘设备中获得更广泛的采用。

🔗 原文

LTCC 方案面向下一代 UWB/BLE 器件

TAIYO YUDEN 展示了面向 UWB 与蓝牙低功耗应用的 LTCC（低温共烧陶瓷）射频元件，针对小型化、可靠无线连接与射频性能等设计挑战。对紧凑型 IoT 与定位设备的天线前端设计有借鉴意义。

🔗 原文

路由器 & OpenWrt

从 25.12-snapshot 降级到 25.12.6 稳定版

一位较新的用户用 owut 将测试路由器刷到 25.12-snapshot，现希望改用稳定版 25.12.6 投入生产。帖子讨论刷写过程中的注意事项，适合正在评估 snapshot 与 stable 取舍的读者参考。

🔗 原文

求推荐 SIM/LTE 一体式 OpenWrt 路由

用户寻找可插 SIM 卡的一体化 LTE 调制解调/路由/Wi-Fi 设备，要求至少 16MB flash、128MB RAM，eBay 价格低于 100 英镑。帖中提及 D-Link DWR-921 C3 作为候选，反映了二手 LTE 路由的选购现实约束。

🔗 原文

ZyXEL LTE3301-M209/Q222 补充串口引脚与波特率

OpenWrt 设备页新增 ZyXEL LTE3301-M209 与 Q222 的串口引脚定义及 bootloader 波特率信息。两款设备均为 MT7620N SoC、64MiB RAM、16MiB SPI-NOR，内置 LTE 模块挂在内部 USB 总线上，适合作为刷机与救砖参考。

🔗 原文

通过 USB 连接 iPhone 获取短信的思路

有用户分享：使用 USB 蜂窝调制解调器时，通常可在所连的 OpenWrt 设备上读取发往其号码的短信，作为带外通道使用。帖子将这一思路延伸到 USB 连接的 iPhone 场景，属于实验性探索，实用性需自行验证。

🔗 原文

D-Link DIR-853 A3 从 OpenWrt 回退原厂固件

用户反映 DIR-853 A3 在 OpenWrt 25.12.6 下 5GHz Wi-Fi 工作异常，而原厂固件正常，因此寻求回退 OEM 固件的方法。这类案例提醒刷机前应确认无线驱动在目标机型上的成熟度。

🔗 原文

编辑小结

本期 Linux 侧的关键词是“合并与收敛”：Redict 退场、生态向 Valkey 集中，稳定内核与安全更新则提醒运维保持跟进节奏。无线领域，私有 5G 的讨论正从“要不要建”转向“如何与既有设施和 AI 负载共存”，规划方法论比覆盖数字更重要。路由器与 OpenWrt 社区的热点仍集中在 LTE 一体机与老设备维护上，snapshot 与 stable 的取舍、无线驱动的机型差异是刷机前必须核实的两个变量。对读者而言，生产环境优先选择稳定版并保留回退路径，仍是成本最低的稳妥策略。
