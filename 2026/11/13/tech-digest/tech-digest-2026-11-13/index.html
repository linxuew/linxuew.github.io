无线与路由技术动态 2026-11-13

发表于2026-11-13|更新于2026-11-13|技术动态
|阅读量:

本期摘要

Rust 1.100 稳定 never 类型并开放 Allocator API 核心部分；OpenWrt 社区迎来 Realtek RTL8197F 平台的首个独立移植，同时 LuCI 与 Dynamic VLAN 文档层面出现若干值得留意的回归问题。

Linux 动态

Rust 1.100.0 发布：never 类型与 Allocator API 核心部分稳定

Rust 1.100.0 正式发布，本次最大变化是 never 类型（!）稳定，以及 Allocator API 的核心部分进入稳定状态。Cargo 新增未使用依赖报告功能，有助于收敛依赖树。对嵌入式与内核周边的 Rust 使用者而言，这两项改动都具备实际工程价值。

curl 三十年：libcurl 装机量估计达三百亿

Daniel Stenberg 撰文回顾 curl 项目三十周年，估计 libcurl 当前安装量约三百亿次。这一数字为粗略估算，因为绝大多数使用者从未主动上报。curl 长期是路由器固件与 OpenWrt 软件包中最常见的网络基础组件之一。

🔗 原文

Project Glasswing 漏洞报告引发维护者不满

VulnCheck 的 Patrick Garrity 分析了 Anthropic 的 Project Glasswing 自 4 月 7 日启动以来提交的漏洞发现：37,966 条报告中仅 7,349 条（19.4%）公开，其中只有 217 条被标记为已修复。低质量的批量报告给上游维护者带来额外负担，这一模式对开源安全流程的可持续性提出了疑问。

🔗 原文

LWN 周报要点：用户命名空间、休眠与 lockdown、glibc tunables

本周 LWN 周报聚焦 Synaptics 专利主张、Git 的 LLM 政策、休眠与 lockdown 的交互、用户命名空间以及 glibc tunables 等议题。简报部分还提到 Asahi Linux 7.3、OpenIndiana 2026.10 与 Firefox 160。对关注内核安全边界与发行版演进的读者，用户命名空间与休眠两篇值得细读。

无线通信动态

GSMA 与 ITU 签署开放电信 AI 意向书

GSMA 与国际电信联盟（ITU）签署了一份关于开放电信 AI 的意向书，表态支持开放式电信模型。该文件不具约束力，且未附带资金安排或时间表。信号意义大于落地意义，后续需观察是否有具体的模型共享与标准化动作。

🔗 原文

Vodafone 上调全年指引，德国市场仍是拖累

Vodafone 上半年有机服务收入增长 5.8%，并上调全年指引，非洲与 Vodafone Business 的数字服务组合是主要动力。德国市场继续拖累整体表现，公司同时提到将进一步采取措施。欧洲运营商的收入结构正在向企业数字化服务倾斜。

🔗 原文

TIM 推进 Poste 整合，重申对 Inwit 的提案

TIM 在财报电话会上表示，已就此前提出的方案向 Inwit 发出正式信函，重申立场。公司同时推进与 Poste 的整合进程。意大利电信市场的铁塔资产整合仍在拉锯，结果将影响当地 5G 站址资源的分配格局。

🔗 原文

读者论坛：电信 AI 的下一步在于多智能体协同

Persistent Systems 的 Kuljesh Puri 在读者论坛撰文指出，运营商已在网络运维、客户服务与规划中部署 AI agent，但孤立系统之间存在决策冲突风险。文章主张共享数据与协调机制是必要条件。这一观点与当前 O-RAN 侧的意图驱动网络讨论方向一致。

🔗 原文

WiFi 标准 & 技术

本期抓取材料中，WiFi 7/8、802.11be/bn 标准进展与互操作认证方向暂无新增条目，故跳过本章节。

芯片 & 硬件

Arteris 互联 IP 累计突破 1000 个客户设计启动

Arteris 宣布其互联 IP 累计达到 1000 个客户芯片设计启动（design starts）。这一里程碑反映出芯片设计中数据搬移效率的重要性正逼近计算本身。对网络与无线 SoC 而言，片上互联与 NoC 的选型会直接影响多核转发与加速器调度的上限。

🔗 原文

西门子 EDA Calibre 负责人谈 EDA 与创新路径

Siemens EDA 的 Juan Rey 接受访谈，介绍其在 Calibre 产品线与 EDA 技术创新的职责与思路。内容偏产业视角，涉及设计验证与制造签核工具的演进方向。对关注先进工艺下签核流程成本的读者有一定参考价值。

🔗 原文

专用无线器件与 SDR 软件 IP 连接 AI 与物理世界

EE Times 刊文讨论将 AI 接入物理世界所需的专用无线器件与 SDR 软件 IP。文章认为下一波智能设备对射频灵活性与软件定义能力的要求会显著提高。这一方向与 Wi-Fi 与蜂窝融合接入的研究脉络相通，值得射频与基带工程师跟踪。

🔗 原文

高光谱成像与半导体进步推动农业传感降本

大豆病害研究表明高光谱成像在作物早期诊断上有潜力，而半导体进步有望让光谱传感对农户变得可负担。文章将器件成本下降视为规模落地的关键变量。边缘侧低功耗感知与无线回传的组合，是这类场景的典型架构。

路由器 & OpenWrt

Rotek RX-23302（RTL8197FH）独立 OpenWrt 6.18 移植

社区用户发布了 Rotek RX-23302（Rostelecom 渠道称 ELECTRA RX23302）的独立 OpenWrt 6.18 移植，基于 Realtek RTL8197F 平台，支持硬件 NAT，可通过 Reset 键配合 TFTP 安装。上游 OpenWrt 尚无该 SoC 支持，作者自述为首次正式移植并欢迎指正。对 Realtek 老平台的社区支持而言，这是一个有价值的增量。

🔗 原文

Keenetic KN-1010（Giga）文档移除两段式构建方案

OpenWrt 设备页更新，Keenetic KN-1010（Giga）移除了两段式构建相关内容。该机型为 MT7621 双频路由器，具备四个千兆 LAN 口、千兆 WAN 的 RJ45/SFP 复合口、两个 USB 口与 128 MiB NAND。OpenWrt 将厂商固件区与存储区拼合为一个虚拟 NAND 设备，文档调整反映安装流程的简化。

🔗 原文

Dynamic VLAN 文档：LuCI 信号强度显示存在已知缺陷

OpenWrt 文档的 Dynamic VLAN 页面更新，记录了 LuCI 在客户端仅连接 wifi-vlan、主 SSID 无客户端时不显示信号强度的问题。文档同时提醒 Dynamic VLAN 的安全注意事项：单 AP 且无需隔离无线客户端的场景无已知问题，其余场景需注意两类风险。生产环境部署前建议先读完该页。

🔗 原文

Askey SBE1V1K：射频识别顺序问题已于 11 月初修复

Askey SBE1V1K 设备页更新 debricking 相关措辞。页面指出，直到 2026 年 11 月初仍存在启动时射频被随机顺序错误识别的问题，该问题已得到解决。作者感谢用户 yangzhg 与 henna 在排查与验证中的贡献。此类多射频识别顺序问题在 MTK 与 QCA 平台上并不罕见，排查思路值得借鉴。

🔗 原文

LuCI 文件管理器 luci-app-footstrap-files 发布

社区发布 luci-app-footstrap-files，面向 OpenWrt 24.10+，可在 LuCI 内浏览路由器文件系统，支持上传下载、重命名、复制移动、修改权限，以及带语法高亮的文本编辑。依赖仅 luci-base 与 cgi-io，无独立后端。对经常在路由器上改配置的运维者较为实用。

🔗 原文

编辑小结

本期 Linux 侧的主线是 Rust 1.100 的工具链能力补齐，never 类型与 Allocator API 的稳定会逐步渗透到系统软件与固件构建流程；而 Glasswing 的低质量漏洞报告则提醒我们，自动化审计的产出必须经过筛选才进入上游流程。无线与路由侧，本期缺少 WiFi 7/8 与芯片厂商的直接动态，热点集中在 OpenWrt 社区：RTL8197F 平台的独立移植说明存量 Realtek 设备仍有活跃的社区维护需求，而 LuCI 与 Dynamic VLAN 的若干回归问题建议在升级前先核对设备页与文档。给读者的建议是：升级 LuCI 相关软件包时先在非关键设备验证 DHCP 与接口统计显示是否正常；对社区移植版本，优先确认硬件 NAT 与无线校准数据的来源可靠性再投入生产。
