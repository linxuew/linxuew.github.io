本期摘要

Git 项目就 LLM 生成代码的接受政策展开投票讨论，OpenWrt 社区则在旧款 Linksys、ASUS 设备移植和新硬件支持上持续活跃。

Linux 动态

Git 考虑以投票方式确定 LLM 政策

Git 项目正就 LLM 生成贡献的接受条款展开讨论，并在近期的 Git Contributor Summit 上成为议题。这一争论是 2026 年各开发项目围绕 AI 辅助代码提交政策分歧的缩影，Git 社区试图以投票形式形成明确规则。

🔗 原文

Kernel prepatch 7.4-rc2 发布

Linus Torvalds 发布了 7.4-rc2 预补丁，并称这是”有史以来最大 rc1 之后的一个大 rc2”。本次体积偏大主要源于遍布代码树的自动化 Coccinelle 更新，剔除这些改动后其余部分相对有限。

🔗 原文

OpenIndiana 2026.10 发布

基于 Illumos（源自 Oracle 停止维护后的 OpenSolaris）的 OpenIndiana 发布 2026.10 版本。该版本为 live 镜像加入 UEFI framebuffer 支持，并更新了大量应用与开发工具。

🔗 原文

周一安全更新汇总

Debian 发布了针对 kernel、libreoffice、rsync、ruby3.3、vim、zlib 等组件的安全更新；Fedora 则更新了 bind、dnf5、gnome-remote-desktop 及一系列 Jackson 相关包，建议相关发行版用户尽快跟进。

🔗 原文

无线通信动态

American Tower：卫星仍需要地面基础设施

American Tower CEO Steve Vondran 向投资者表示，公司认为卫星与地面无线基础设施是互补而非竞争关系。这一表态反映出卫星通信崛起背景下，铁塔运营商对自身定位的重新阐释。

🔗 原文

SK Telecom 目标 12 月商用 5G SA

随着移动业务回暖，SK Telecom 计划在 12 月推出 5G SA 服务。面向 6G，该公司表示正参与技术研发与标准化活动，同时持续跟踪全球主要技术进展与趋势。

🔗 原文

WiFi 标准 & 技术

芯片 & 硬件

Imagination CTO 谈图形、计算与 AI 融合

Imagination Technologies CTO Ed Plowman 负责技术战略、先进架构研究与长期创新，重点关注图形、计算与人工智能的融合，推动下一代高效能架构设计。

🔗 原文

Celestica 与 Broadcom 谈集成光学

在 OCP Global Summit 上，Celestica 与 Broadcom 介绍了集成光学如何为 AI 数据中心降低功耗与延迟，属于本次峰会合作伙伴访谈内容。

🔗 原文

DeepX 第二代芯片流片，LPDDR5x-PIM 预期 6.7 倍性能提升

DeepX 面向机器人等边缘市场流片第二代 AI 加速器，可在 5W 以内设备端运行大语言模型，并借助 LPDDR5x-PIM 方案预期实现 6.7 倍性能提升。

🔗 原文

AMDGPU 驱动提交 GFX13（RDNA5）支持补丁

继年初 AMDGPU LLVM 后端出现 GFX13 支持后，面向 AMDGPU Linux 内核图形驱动的 GFX13 补丁现已公开，该图形 IP 大概率对应 RDNA 5。

🔗 原文

路由器 & OpenWrt

在 Linksys E8400 上安装 OpenWrt

有用户基于”寻找与受支持型号硬件/FCC ID 相同的未支持机型”的思路，购入 Linksys E8400。该机与已获支持的 E8350 拥有相同 FCC ID 和硬件，但无法直接刷入现有 E8350 固件，帖子记录了移植尝试。

🔗 原文

ASUS RT-AC1200G+ 设备页创建

OpenWrt 维基新增 ASUS RT-AC1200G+ 条目，注明该设备未获官方支持、无设备定义。社区基于同 SoC、交换芯片和 2.4 GHz 射频的 Tenda AC9 目标，配合修改后的 device tree 构建了社区镜像。

🔗 原文

Acer Predator W6X extroot：RTL9210 NVMe USB 适配器启动时未被识别

用户在 OpenWrt 25.12.6 上为 Acer Predator W6X 配置 NVMe SSD 作为 extroot，遇到启动阶段 USB 适配器未被检测的问题。SSD 与适配器在系统完全启动后工作正常，疑与启动时序或驱动加载顺序有关。

🔗 原文

Cudy WR1200 v2.1/2.0（R26）请求官方支持

用户为 MT7628、16MB Flash 的 Cudy WR1200 v2.1（v2.0 硬件相同）提交官方支持请求，并提供了完整 flash dump 与诊断信息。Cudy 技术支持已确认，一旦 OpenWrt 加入对应 target/profile 便可推进。

🔗 原文

MikroTik RB450G 页面更新：VLAN 交换机端口

OpenWrt 维基更新 MikroTik RouterBoard RB450G 条目，该设备具备较快处理器、千兆以太网及较大内存与闪存。随着 OpenWrt 18 的到来，其安装流程已显著简化。

🔗 原文

编辑小结

本期 Linux 侧最值得关注的是 Git 项目围绕 LLM 贡献政策的制度化尝试，这类规则很可能被其他开源项目借鉴。内核 7.4-rc2 因自动化工具改动而体量偏大，提示维护者审阅时需区分机械变更与实质修改。OpenWrt 社区依旧围绕”同硬件不同型号”的移植路径发力，E8400 与 RT-AC1200G+ 两个案例都说明 FCC ID 与 SoC 比对是低成本适配的有效起点。硬件层面，边缘 AI 加速器与 RDNA5 驱动的推进值得持续跟踪。
