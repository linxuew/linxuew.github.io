本期摘要

Linux 7.4 合并窗口开启，slab 更新带来约 24% 的吞吐提升；OpenWrt 侧 Ubiquiti UCG-Fiber 的 10G 网关设备页进入编写阶段，同时 25.12.6 升级后 odhcpd 日志刷屏问题引发讨论。无线侧，6G 频谱共享与测试复杂度成为焦点。

Linux 动态

Linux 7.4 合并窗口第一部分进展

7.4 合并窗口开启以来，已有 6,753 个非 merge changeset 进入主线，后续预计还有更多提交，窗口甚至可能延长至三周。LWN 梳理了这批首批合入的新特性。

寻求更小的内核栈

全球内存芯片短缺背景下，系统开发者重新聚焦内存占用削减。本文来自 2026 年内存管理 microconference，讨论缩小内核栈的可能路径及其取舍。

Linux 7.4 合入 Slab 更新，性能明显改善

slab 子系统 pull request 已并入 Linux 7.4。对终端用户而言变化不算轰动，但其中一项改动在内存管理子系统基准测试中带来约 24% 的吞吐提升。

IBM 与 Microsoft 为 OS/2 开发的高性能文件系统 HPFS，成为最新一个面临从 Linux 内核移除的文件系统驱动。此前已有多个老旧文件系统被清理。

路由器 & OpenWrt

Ubiquiti UCG-Fiber 设备页编写中

Ubiquiti UniFi Cloud Gateway Fiber（UCG-Fiber）是一款基于 Qualcomm IPQ9574（四核 Cortex-A73）的 10G 网关，配 Realtek RTL8372N 交换芯片。OpenWrt 设备页目前处于 under construction 状态，欢迎社区补充。

🔗 原文

OpenWrt 下载不可用

有用户反映无法从 downloads.openwrt.org 的 25.12.6 releases targets 目录下载镜像。该帖暂无更多回复，值得关注是否为镜像或发布流程问题。

🔗 原文

升级 25.12.6 后 odhcpd 反复刷 RA SLAAC 相关错误日志

用户通过 LuCI attended-sysupgrade 升级到 OpenWrt 25.12.6 后，odhcpd 持续输出 “failed to send to ff02::1 (destination address required)” 错误。论坛讨论如何限制这类高度重复的日志。

ASUS TUF-AX6000：留用还是换机？

用户以约 40 欧元二手购入 ASUS TUF-AX6000，认为性价比不错，但在 VLAN、整体性能、更新与安全方面存在限制，因而纠结是否继续使用。讨论涉及 OpenWrt 支持情况。

🔗 原文

Xiaomi AX3600 设备页更新 NSS 与 PPE 实际状态

Xiaomi Mi AIoT Router AX3600 为 802.11ax OFDMA/MU-MIMO 三频路由器，2.4GHz 为 QCN5024 2×2/40MHz ax，5GHz 为 QCN5054 4×4/80 或 2×2/160MHz ax。wiki 更新了 NSS 与 PPE 的当前状态说明。

编辑小结

本期 Linux 侧信息量集中在 7.4 合并窗口与内存管理：slab 的约 24% 吞吐提升对高负载路由与网关场景有实际意义，而“更小内核栈”的讨论也与内存短缺背景呼应。OpenWrt 社区则呈现典型的版本升级后遗症——25.12.6 上 odhcpd 的 RA 报错刷屏，建议升级前先备份并关注论坛修复进展。硬件方面，IPQ9574 平台的 UCG-Fiber 进入 OpenWrt 设备库视野，10G 网关的开源固件支持值得持续跟踪。无线侧 6G 频谱共享讨论升温，短期内对家用路由影响有限，但会逐步影响监管与测试框架。
